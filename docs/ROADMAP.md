- 平台：PC 优先，**同步预留手机版**（横屏、触控、最小点击区 ≥ 44px、ETC2/ASTC 纹理）。
- 联机：暂不实现，P1 中以 `Action` 序列化 + `GameController` 单一入口的方式预留。
- 素材：免费可商用素材、AI 生成、代码程序化生成均可，以效果为先；全部登记于 `assets/LICENSES.md`。
- 定位：免费开源。
- 名称：暂定《百工雅集》。
